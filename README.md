# 倉庫番（第13回）

授業で配布された演習版を基に、プレイヤーの移動・壁判定・箱押しを実装したプログラムです。

## 実行方法

Python 3で実行します。外部ライブラリは不要です。

```powershell
python sokoban_exercise.py
```

## 操作

キーを入力してEnterを押します。

- W / A / S / D：上下左右へ移動
- U：1手戻す
- R：現在のステージを最初からやり直す
- Q：終了

すべての箱をゴールへ運ぶと次のステージへ進みます。全3ステージです。

## 改良箇所

- `can_enter`：移動先が盤面内で、壁ではないかを判定する。
- `push_crate`：箱の先が盤面外・壁・別の箱でない場合だけ箱を動かす。
- `apply_move`：移動できる場合だけ、プレイヤー・箱・履歴・移動回数を更新する。

移動、盤面外・壁・箱同士の衝突、Undo、再開、終了、全ステージのクリアを確認しています。
