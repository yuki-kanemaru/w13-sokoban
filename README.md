# 倉庫番（第13回）

授業で配布された演習版を基に、プレイヤーの移動・壁判定・箱押しを実装したプログラムです。演習の3つのTODOを終えたあと、操作の案内・進捗表示・ステージ追加・自動テストを加えました。

## 実行方法

Python 3で実行します。外部ライブラリは不要です。

```powershell
python sokoban_exercise.py
```

## 操作

キーを入力してEnterを押します。

- W / A / S / D：上下左右へ移動
- U：1手戻す
- R：現在のステージを最初からやり直す
- Q：終了

移動できないときは案内を表示します。すべての箱をゴールへ運ぶと次のステージへ進みます。全4ステージです。

## 画面の見方

- 移動回数：現在のステージで動けた回数。
- 残りの箱：ゴールに乗っていない箱の数。
- ステージクリア時に、そのステージの手数と全ステージの合計手数を表示します。

## 改良箇所

- `can_enter`：移動先が盤面内で、壁ではないかを判定する。
- `push_crate`：箱の先が盤面外・壁・別の箱でない場合だけ箱を動かす。
- `apply_move`：移動できる場合だけ、プレイヤー・箱・履歴・移動回数を更新する。
- `remaining_crates`：ゴールに乗っていない箱を数える。
- `start`：移動できないときと未対応キーの案内、クリア時の手数表示を担当する。
- `MAP_TEXT`：2つの箱を運ぶステージ4を追加した。

## 動作確認

```powershell
python -m unittest -v test_sokoban
```

13件のテストで、マップの検証、壁と盤面外の判定、箱が押せない条件、押せたときの更新、Undo、残りの箱数、全4ステージのクリアを確認します。

手で確かめた内容は、移動、盤面外・壁・箱同士の衝突、Undo、再開、終了、全ステージのクリアです。
